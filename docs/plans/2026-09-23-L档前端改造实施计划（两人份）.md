## 一、总目标与边界

**目标形态**：左栏「对话 / 功能」两类入口 + 主栏对话流（消息正序、输入区贴底），
面板内容与**全部真实性标注一字不改**。

**边界（本轮不做，也不是遗漏）**：

| 不做的事 | 为什么 |
|---|---|
| 引 UI 框架（assistant-ui / Ant Design X / AI Elements） | 栈约束（计划书 L190「无路由、无状态库、无 CSS 方案」）+ 会把依赖表、许可证检查、打包体积连锁改动；净收益近零（详见方案 §四） |

| 浏览器视觉验收 | 本环境无法做（`I8`）→ 留给人工，**不许用 `verify:render` 冒充** |

## 四、P2 任务卡（后端接口与测试）

> ⚠️ **串行声明**：本包**改契约**（`packages/contracts`），按项目纪律**同时只能有一个契约变更在飞**。
> 开工前需 A/B 确认；落地时必须**同批**更新 `docs/知识库.md` §5 与 `docs/tech/`。

### P2-1 会话列表接口（最小可用）

- **契约（加性、可选）**：
  ```ts
  // packages/contracts/src/session.ts（新增导出）
  export interface SessionSummary {
    sessionId: string;
    createdAt: string;      // ISO
    updatedAt: string;      // ISO
    materialVersion: number;
    materialCount: number;
    hasStudentMaterial: boolean;
  }
  export interface SessionListResponse { sessions: SessionSummary[] }
  ```
- **服务端**：`GET /api/sessions` → 返回本机会话摘要（**只回摘要，不回材料正文**：
  评委/学生都不需要从列表里泄露内容）。按 `updatedAt` 倒序；空列表返回 `{ sessions: [] }`。
- **验收**：`verify:all` 增 `store` 侧摘要纯函数断言；`verify:flow` 增 3 条（空列表 / 造两个会话后各字段正确 / 不返回材料正文）。
- **回滚**：删路由与契约新增块即可（**加性字段**，删除不影响既有消费方）。

### P2-2 按 id 恢复会话（决定要不要做）

- **难点**：`history`（问答历史）目前在**前端**，服务端没有 → 真正"恢复历史对话"需要
  ① 服务端持久化问答记录，或 ② 前端把自己那份历史存本地并按 `sessionId` 归位。
- **建议**：先做 **②**（纯前端，不占契约闸）：`sessionStorage` 按 `sessionId` 存历史，
  刷新后按 `/api/session` 恢复材料与图谱，历史从本地读回。
  **只有在需要"换设备接着聊"时才做 ①**（那才是真正的契约与存储变更）。
- **验收**：刷新页面后会话标题、材料版本、问答条数与刷新前一致；**服务端重启后旧会话 404**
  时给出中性提示并清理本地记录（不许静默丢失）。

### P2-3 测试与回归维护（与 P2-1/2 同轮）

- `verify:render` 的**外壳节**（第 9 节）随 P2 增加"多会话列表"断言；
- 新增 E2E：`verify:flow` 走"两个会话并存 → 切换 → 各自材料互不污染"；
- **红/绿证据**：每条新断言都要能证明"改坏了会红"（本项目被 `I24` 的恒真断言坑过）。

### 5.2 解耦收益（本轮最实的一块）

`panels-should-not-import-state-internals` **6 → 0**，并按项目惯例（每条规则在**自己清零之后**转 `error`）转为**阻断**。
**红/绿证据**（已实测，防"规则是摆设"）：

1. 改 `severity: 'error'` 后，临时在 `MaterialPanel.tsx` 加回一句
   `import type { WorkbenchState } from '../hooks/useWorkbench'`
   → `lint:boundaries` **exit 1**，输出 `error panels-should-not-import-state-internals: …MaterialPanel.tsx → …useWorkbench.ts`；
2. 移除该行 → `✔ no dependency violations found (85 modules, 226 dependencies cruised)`，**exit 0**。

### 5.3 人工验收（**必须人工，不许自动化代替**）

1. 宽屏：左栏常驻、点「功能」各项主区随之切换；「本页说明」默认收起；
2. 窄屏（≤900px）：左栏收成抽屉，点面板左上按钮展开，选中后自动收起；
3. 暗色模式：主色变亮档、文字对比度正常、无"深底深字"；
4. 对话流：提问后消息出现在**下方**、输入框始终贴底、`mock` 标记与验证状态仍在；
5. 动效：切换与消息入场为 180ms 淡入上移，**无弹跳**；系统开启"减少动态效果"后动效消失。

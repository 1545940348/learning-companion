两个目标，第一个是阻断项。

1. **（阻断）确认模型调用在部署环境成立。** 本机验证依赖 WorkBuddy 桌面端本地网关
   （`127.0.0.1:6657`），部署环境没有该网关。若此项不成立，说明书 1.3"线上真实接入模型"
   这一成功标准无法达成，整个演示方案需要改（例如改为本地演示 + 录屏）。
2. **冻结五接口契约**，使 A 与 B 可完全独立开工。这是说明书 C1 的验收目标，
   也是三人并行开发的前提。

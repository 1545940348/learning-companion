## 二、目标形态

```
┌──────────────┬────────────────────────────────────────────┐
│ 微积分学伴    │  材料 · 已提交 2 份            [mock 演示]    │ ← 顶栏沿用现有页头/横幅
├──────────────┼────────────────────────────────────────────┤
│ ▸ 新对话      │                                            │
│              │   你：这题的导数怎么求？                     │
│ 会话          │   ────────────────────────────────         │
│  ▸ 本次会话   │   学伴：……（来源 2 处 · 验证：unverified）  │
│  ▸ 昨天 21:03 │                                            │
│              │   ┌──────────────────────────────────────┐ │
│ 功能          │   │ 输入你的问题…            [语音][图片] │ │
│  ▸ 材料       │   └──────────────────────────────────────┘ │
│  ▸ 知识点     │                                            │
│  ▸ 图谱 ●3    │                                            │
│  ▸ 练习       │                                            │
│  ▸ 画像       │                                            │
└──────────────┴────────────────────────────────────────────┘
```

要点：
- **主栏默认是对话流**（把现在的「答疑」面板提升为主视图）；
- **左栏两类项**：「会话」（切换对话上下文）与「功能」（把主区切到材料/知识点/图谱/练习/画像）；
- **六面板的内容与文案一律不改**，只换容器与入口——这是把回归风险压到最低的关键。

## 三、当前前端实况（2026-09-23 实读）

| 项 | 事实 |
|---|---|
| 结构 | `main.tsx`(19) → `ErrorBoundary` → `App.tsx`(168)：`header` → 通知条 → `<main class="layout">` 内**两个 `.column`**（左列 Material/Knowledge/Graph，右列 Tutor/Quiz/Profile）→ `footer`。**单页纵向双列，无 tab、无路由** |
| 状态 | 唯一 hook 调用点 `App.tsx:24`；六面板全部收 `wb: WorkbenchState & WorkbenchActions`，**无一面板自己调 hook** → **布局改造不动状态层** |
| `useWorkbench.ts` | **1145 行**（已超体积阈值，`I43`）；`useState` 16 个、`useRef` 3 个；方法按域分：材料／图谱／答疑／练习／画像／生命周期／提示重试／联动 |
| API | 唯一 client `api.ts`(199)，`request()` 统一超时与取消；hook 内 12 处 `api.*` |
| 样式 | `index.css` **981 行 / 约 153 个 class / `:root` 19 个 CSS 变量 / 已有 `prefers-color-scheme: dark`** |
| 依赖 | 运行时**只有 3 个**：`@lc/contracts`、`react@^19`、`react-dom@^19`。**无路由、无状态库、无 UI 库、无 Tailwind** |
| 产物 | `apps/web/dist/assets/index-*.js` 约 **264 KB**、CSS **11.9 KB** |
| 联动 | `focusedNodeId` 由 hook 持有，`KnowledgePanel` ↔ `GraphPanel` 读同一字段（**共享 state，非自定义事件**） |
| **回归耦合** | **`verify:render`（125 项）不 import `App`**，而是逐个 `renderToStaticMarkup` 单面板并断言 `html.includes('中文文案')` → **布局大改不会让它大面积失败**；`verify:ui-flow`（48 项）**零前端耦合** |
| 明文约束 | 计划书 L190「**无路由、无状态库、无 CSS 方案**」；`tech/2026-09-17-云托管部署说明.md:171`「前端没有路由表，单页+面板切换」 |

> 两条**决定性的好消息**：① 布局改动**不触**契约层与 API（一个接口都不动，**不占契约串行闸**）；
> ② `verify:render` 不渲染整页 ⇒ 改造的回归代价主要在**新增断言**，而不是**修既有断言**。

## 四、开源框架选型（2026-09-23 检索结果）

| 框架 | 许可证 | 栈要求 | 与本项目的适配 | 结论 |
|---|---|---|---|---|
| **assistant-ui** | MIT（Y Combinator 背书，11.3k★） | React 18/19，**headless**，`Thread`/`Message`/`Composer`/`ThreadList` 可自由组版式 | 组件划分**正是目标形态**；但它的 runtime 面向 **streaming**（AI SDK/LangGraph/custom data-stream），本项目 `/api/tutor` 是**一次性 JSON**，需自写适配器 | **借范式，不整体引入** |
| **Vercel AI Elements** | 见其 LICENSE（需逐字核） | **Next.js + Tailwind + shadcn/ui + AI SDK** | **栈不符**（本项目 Vite + 手写 CSS，且明文"无 CSS 方案"） | 不推荐（**组件划分值得抄**） |
| **prompt-kit** | 见其 LICENSE | shadcn + Tailwind | 同上；其「**Sidebar with chat history ＋ Conversation**」版式与本方案目标**几乎一致** | 不推荐引入（**版式可照抄**） |
| **Ant Design X（`@ant-design/x`）** | MIT | React ＋ antd v5（cssinjs） | 组件最对口（`Conversations`/`Bubble`/`Sender`）；代价：样式**双轨**（antd token vs 现有 19 个 CSS 变量）、体积上涨、SSR 断言需适配 | **若要"现成"，就选它**（代价明确） |
| **TDesign Chat（腾讯）** | MIT | React / Vue | 同类问题 | 备选 |
| **CopilotKit**（36.3k★） | MIT | React + AI SDK | 定位是 **in-app copilot**，不是"左栏＋主栏"平台壳 | 不推荐 |
| **Lobe Chat / Open WebUI / NextChat** | MIT | 整套应用（Next.js / Python） | 是**完整产品**，不是可嵌入的壳 | 不推荐 |
| **@bytecrafts/agent-ui-components** | 待核 | 强依赖 LangGraph SDK | 依赖链过重 | 不推荐 |

**结论：没有"零成本直接套用"的框架**——因为本项目刻意保持极简栈（计划书 L190 明文）。
最省事的路线是 **「借版式与组件划分、自己实现」**：只新增 3–4 个壳组件，复用现有 CSS 体系。

**若一定要引框架**，唯一合理选项是 **Ant Design X**：给 **+2–3 人日**（样式对齐 + SSR 断言适配 + 依赖/许可证/体积三处收口），
收益是省下自绘组件的时间——**净收益接近零**，故不推荐。

## 七、验收判据（每档都要）

1. **面板文案零差异**：改造前后 `verify:render` 的**既有 125 项全部仍绿**（这是硬判据，证明内容没被顺手改掉）；
2. **新增断言**：壳结构（左栏项、主区单一视图、选中态）与消息态（pending/失败/重试）各有断言，且**改坏了必须变红**（配红/绿证据，防 `I24` 那类恒真断言）；
3. `npm run typecheck` 0 error；`npm run verify:flow`（48）与 `verify:serve-web`（45）不受影响；
4. **人工走查**：按《界面验收清单》新增节逐条点一遍（含窄屏与暗色）；
5. 契约层**零改动**（`packages/contracts` 一行不改、`/api/*` 一个不动）—— 若发现必须改接口，**停手先报告**（会占契约串行闸）。

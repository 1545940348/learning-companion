## 2. 关键实现决定（都留了理由，避免后人"顺手改回去"）

1. **安全头挂在最前面，且单独成模块**：写在 `mountWebApp()` 里会让 `/api` 与 404 漏掉
   （`mountWebApp` 按设计在 `/api` 路由之后调用）。为此补了一条**源码级断言** ——
   验证脚本用的是自建 Express 管线，光在脚本里挂上证明不了入口文件挂对了位置。
2. **CSP 用上了比计划书示例更严的版本**：实测"构建产物无内联脚本、全仓 0 处 `style={{}}`、
   CSS/组件无任何外链资源"→ `script-src 'self'` 与 `style-src 'self'` 都**不需要** `'unsafe-inline'`。
   另加一条断言：CSP 里**不得出现** `unsafe-inline` / `unsafe-eval`。
3. **刻意没上三项头**（各有理由，见模块注释）：`require-trusted-types-for`（会打挂页面，留阶段 8）、
   `Cross-Origin-Embedder-Policy`（计划书结论"评估后不加"）、HSTS **仅在 `req.secure` 或
   `x-forwarded-proto: https` 时发送**（HTTP 站点发 HSTS 无意义且会把站点锁死）——
   后两条都有对应断言（HTTP 下必须不带、声明 https 时才带）。
4. **`ErrorBoundary` 的断言写法**：`renderToStaticMarkup` 下**错误边界不生效**，
   所以**不能**写"渲染一个会抛错的子组件、断言出现兜底文案"——那种写法要么假失败、
   要么被绕过后恒真（同 `I24` 的教训）。改为"直接调 `getDerivedStateFromError` 做纯逻辑断言"
   + "无错时原样渲染子树"两条。
5. **超时与取消必须说不同的话**：超时是失败（可重试、写明 120 秒）；取消是学生主动动作
   （中性提示、**不给重试按钮**）。抽成纯函数 `describeAbort` 以便断言 ——
   混成一句话等于把"我自己按的取消"渲染成"你的操作失败了"（无据声明，同 `I20⑦`/`I33` 一类）。
6. **`CLIENT_TIMEOUT_MS` 放前端常量、不进契约**：它描述浏览器侧行为，不是服务端契约。
   值 120 s 的理由（必须大于服务端单次调用上限 90 s）写进 `知识库.md` §7。
7. **卡 5 一律"只告警"**：阶段 0 的目标是"边界被打破时能立刻看见"，不是"先把存量修完"
   （`useWorkbench.ts` 994 行、6 个面板直连 hooks 都是阶段 1–4 的活）。设成 error 会让命令恒红而被无视。
   **`server-must-not-reach-into-web` 除外**：它没有存量违规，直接设 `error`。

## 4. 本轮新踩到并已登记的坑

1. **`npm install` 会把 rollup/esbuild 的平台二进制剪掉**（`I39`，npm/cli#4828）：
   装完 5 个开发期依赖后 `node_modules/@rollup/` 与 `@esbuild/` **整个目录消失** →
   `npm run build` 报 `Cannot find module @rollup/rollup-win32-x64-msvc`。
   **注意这不止影响 Linux 容器（`Dockerfile` 里已有一段说明），本地 Windows 同样会中**。
   临时处置见 `todo.md` 的 `I39`；根治要重新生成含全平台可选依赖的锁文件。
2. **`npm install` 在本机第一次会因 safe-delete 失败**（尝试 trash 平台包时报
   *Some operations were aborted*），**重试即成功**（本轮实测）。
3. **`scripts/check-licenses.mjs` 在重构期间会崩**：它按 `git ls-files` 读全部被跟踪文件，
   而"跟踪着、工作区已移走"是重构期间的**正常中间态** → `readFileSync` `ENOENT`。
   已加一层"跳过工作区不存在的文件"，并写明理由。
4. **删除其实可用**：`rm` 传 **Windows 绝对路径**（`rm "D:/…"`）即可，递归同理。
   根因是垫片把 MSYS 路径原样交给 `genie-trash`，被判为相对路径。已写进 `知识库.md` §13.2。
5. **`.git/` 之外的问题**：`README.md` 这类文件**shell 写不进去**（`PermissionError`），
   必须用宿主侧编辑工具 —— 与"跨命令改已有文件被拒"是同一族限制。

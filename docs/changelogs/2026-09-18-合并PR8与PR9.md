## 3 合并前落的四处修正

### 3.1 `scripts/pack-deploy.mjs`：排除名单与实际目录名不匹配（P1）

- **问题**：`EXCLUDE_DIRS` 写的是 `npm-cache`，仓库里实际的目录是 **`.npm-cache`**（`.gitignore` 可证）。
  名字差一个点，判定完全失效；且脚本是**按文件系统遍历、不读 `.gitignore`**，所以也没有 `*.log` 规则。
- **实测**（按同一套规则只统计不拷贝）：修复前会打包 **1565 个文件 / 368.67 MB**
  —— 其中 `.npm-cache` **1254 个 / 366 MB**、`*.log` **185 个 / 1.5 MB**。
- **为什么危险**：末尾的自检只查 `node_modules` / `.git` / `.env` **三个名字**，
  于是一路打印「✅ 未发现 … 可以上传」。PR 自称的「129 个文件 / 1.21 MB」在当前仓库状态下**复现不出来**。
- **改法**：① 排除名单补齐**点开头的缓存目录**与 `.pnpm-store` / `.yarn` / `build` / `out` / `coverage` 等；
  ② 新增 `EXCLUDE_SUFFIXES = ['.log']`；③ 自检与排除名单**同源**（任何名单内目录都报）、
  ④ 新增**体积闸门**（超过 10 MB 一律报问题）+ 按扩展名的体积构成；
  ⑤ 新增 `PACK_DEPLOY_OUT` 环境变量，使打包结果可以在仓库之外真跑一遍来验证。
- **修后实测**：**143 个文件 / 1.44 MB**，自检通过。同时修正 `.dockerignore`（同一处笔误，会让构建上下文多带 366 MB）。

### 3.2 `serve-web.ts`：SPA 回退范围过宽（P2）

- **问题**：回退只排除了 `/api` 前缀。实测（**真实 vite 产物**，不是占位文件）：
  `GET /assets/not-built.js`、`GET /favicon.ico`、`GET /.env` 全部返回 **200 + 首页 HTML**。
- **后果**：构建产物哈希变了、或资源漏打进镜像时，浏览器拿到 HTML 却按 JS 解析
  （`Unexpected token '<'`），而状态码是 200 —— **"资源没打进镜像"看起来像"页面正常"**，
  正是本模块头注释里写"错误极难定位"的那一类。
- **改法**：回退前加两道排除 —— `isApiPath`（`=== '/api' || startsWith('/api/')`，
  避免 `/apifoo` 这类前缀相近的路径被误伤）与 `looksLikeAsset`（末段带扩展名的不回退）。
  前端当前没有路由表（单页 + 面板切换），现有路径没有一个带扩展名，**收紧不会挡住任何真实路由**。
- **断言**：`verify-serve-web` 新增 4 条，并把原有两条从"只断言不是首页"升级为
  **"状态码 + 内容"双断言**（只断言"不是首页"是锁不住东西的 —— 返回 500 也能满足）。
- **红/绿证据**：新断言在**修复前的代码上 4 条全红**（`14 通过 / 4 失败`），修复后 **18 通过 / 0 失败**。

### 3.3 云托管部署说明：补上「访问提示中间页」（P1）

- **问题**：文档把"免备案"列为最关键选型理由，并由此在验收里写"**无痕窗口打开：无需任何配置即可使用**"。
  但官方另一份现行文档（`docs.cloudbase.net/service/alias`）写明：默认域名在浏览器**直接访问**时会先展示
  **「访问提示中间页」**（须点「确定访问」），且「默认域名**仅建议用于开发测试**，严禁用于正式生产或**分发给大规模用户**」，
  生产环境用默认域名「可能因流量触发风控而被关停」。
- **引文本身没错**（腾讯云官方原文确实是"若采用云托管提供默认域名访问自身则无需进行备案"）——
  错的是**由它推出的体验结论**。而"把链接发给评委"恰好落在官方点名的慎用场景里。
- **改法**：§一 增补上述原文摘录与影响/处置表；§三 验收第 5 条改为"出现中间页 → 点确定 → 进入"；
  §三 验收第 4 条注明依赖 `I13` 修复；§四 增加 `verify:predeploy`；§七 标注 `P-C20` 已脚本化；
  §八 真实性声明按实况重写（含"构建阻断项已消失"与真实产物复验结果）。

### 3.4 `scripts/check-sensitive.mjs`：计数不是常数（P2，文档口径）

- **问题**：`if (untracked.length > 0) ok('其中包含 N 个待提交的未跟踪文件')` ——
  工作区**干净时这条不计入**，于是 `sensitive` 在 14/15、`verify:repo` 在 32/33、
  合计在 357/358 之间漂移，而 README / 知识库 §9 / todo `P-C5` 三处把 33 与 358 写成了定值。
- **实测**：干净工作区复跑得 `190 / 36 / 11 / 88 / **32** = **357**`，与文档差 1。
- **危害不是"数字难看"**：任何人按 README 在干净树上复核都会看到 357，然后怀疑是自己跑错了。
- **改法**：改为**无条件断言**（`0 个未跟踪文件`同样是一条应当被断言的事实）。
  复跑：`repo = 15 + 10 + 8 = 33`，合计 **358**，与文档重新对上且恒定。

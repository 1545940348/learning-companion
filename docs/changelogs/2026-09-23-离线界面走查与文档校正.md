## 一、根因：`I8` 的结论建立在"只有一条路"的假设上

`I8` 原写法：**"环境无 `agent-browser` 且不允许 `npm install -g` ⇒ 无法做浏览器视觉验证"**。

前半句是对的（`agent-browser` 确实没装，`-g` 确实被禁），**但结论不成立** ——
`agent-browser` 只是**一条**路径。实测发现本机：

| 事实 | 实测证据 |
|---|---|
| **Chromium 早已存在** | `%LOCALAPPDATA%\ms-playwright\` 里有 `chromium-1223`、`chromium_headless_shell-1223`、firefox、webkit |
| 无头外壳可直接用 | `chrome-headless-shell.exe --version` → `Google Chrome for Testing 148.0.7778.96` |
| 驱动壳可装且不违规 | `playwright-core@1.63.0` 装进 **`C:\Users\Acer\.workbuddy\binaries\node\workspace`**（隔离工作区）—— **不违反"不许 `-g`"、不进项目依赖** |

⇒ **不需要下载任何浏览器、不需要全局安装**，也能截图与点击走查。

**用户那句抱怨的解法因此有两层**（都交付了）：

1. **`present_files` 传 `http://127.0.0.1:3000`** → 在内置浏览器面板打开，**改完 `build` 刷新即可**，
   全程不出本机；
2. **`.learnbuddy/tools/walkthrough.js`** → 自动点遍六视图、截窄屏抽屉、**并收集 `console` / `pageerror`**。

一眼能看出来的事实（**这是第一次真正"看见"成品**）：

- 左栏「对话 / 功能」两类入口、图标与文字并排、选中态有底色 —— 与设计一致；
- 顶栏两个徽标如实显示 `mock` 与 `mathjs`，`mock` 演示横幅完整；
- 对话流空态给的是**可点示例问题**，不是说明性小字；输入区贴底、模式三选一在该行右侧；
- 窄屏（820px）左栏变**抽屉**，展开时浮在内容之上带阴影；
- 灰度配色（主色墨绿 ＋ 中性灰阶）确实"不花哨"。

**踩到并解决了三个坑**（已写进技能）：

1. `--screenshot` 不加 `--virtual-time-budget` → **截到全白首屏**；
2. Chromium 启动**必须 `--no-sandbox`**（否则 `Sandbox cannot access executable … 拒绝访问 (0x5)`）；
3. 项目 `package.json` 是 `"type": "module"` ⇒ `.js` 走 ESM，而 **ESM 不读 `NODE_PATH`**，
   `playwright-core` 又刻意不装进项目依赖 ⇒ 脚本里用 `createRequire(import.meta.url)` 桥接。

## 五、**没做**的事（有意）

| 未做 | 原因 |
|---|---|
| **把走查接进 `verify:` 链**（做成 `verify:ui-walk` 之类，纳入回归计数） | 它依赖**本机 Chromium 路径**与**隔离工作区的 `playwright-core`**，而这两样**不在项目依赖里** ⇒ 接进 `verify` 链会让"别人 clone 下来就能跑"这条前提失效。**先留在本地工具层**（`.learnbuddy/tools/`），要转正需先决定"是否把 `playwright-core` 写进 `devDependencies`" |
| **E2E 用例集**（点击走完整闭环：上传材料 → 出知识点 → 补缺口 → 提问 → 练习 → 画像） | 属"视觉回归升级"的真正内容，工作量与 §五 的取舍绑定，**建议先不做** |
| **favicon** | 走查会报一条 404（无害）。要消掉只需在 `index.html` 加 `<link rel="icon" href="data:,">`；本轮未做，因为**它属于产品决定**（是否要图标），不是缺陷 |
| 历史留档的旧表述 | 按"不涂改历史"**不动**（`changelogs/`、`reviews/`、`2026-09-18 计划书`） |

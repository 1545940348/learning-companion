## 四、接口扩展（需 B 确认）

```ts
// packages/teaching/src/model.ts
export type ModelInput = string | ModelInputBlock[];
export type ModelCaller = (input: ModelInput, options?: ModelCallOptions) => Promise<string>;
```

**为什么做成联合类型而不是直接改成数组**：现有调用点全部传字符串，改成数组会波及教学模块多处代码。
联合类型**向后兼容**，现有纯文本调用点无需任何改动即可继续编译。

**为什么必须扩**：队友原接口是 `(prompt: string) => Promise<string>`，字符串进字符串出，
**没有位置放图片**。而拍照提问是作品核心卖点，B1 图文解析与 E12 就地纠错都依赖图片输入。

**该文件属于 B 的模块**，本次由 C 按用户指示改动，需 B 确认。

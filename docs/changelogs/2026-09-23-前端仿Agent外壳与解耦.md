### 1.3 双色与动效（对应 UI 要求）

- **双色**：主色只用 `--accent`（墨绿）＋ 中性灰阶；琥珀／砖红／蓝**仅用于语义状态**，不做装饰；
- **动效经典**：`180ms` + `cubic-bezier(.22,.61,.36,1)`（ease-out，**无弹跳**），
  只动 `background / color / border-color / transform / opacity`（**不动布局属性**，避免重排）；
- **无障碍**：`prefers-reduced-motion` 下动效全关；选中态有 `aria-current` 而非只靠颜色；
- **少小字**：四段如实标注**收进**左栏底部「本页说明」折叠区（是**收纳不是删除** —— 它们是验收判据）。

### ★ 构建期抓到的一个真错误（值得记一笔）

把 `totalTextLength` 搬到 `app/model/materials.ts` 后，只做了 `export … from`（再导出），
**但 hook 内部第 495 行还在调用它** → `tsc` 报
`error TS2304: Cannot find name 'totalTextLength'`。

**是 `npm run build` 抓到的，不是 `typecheck`** —— 因为 `typecheck` 那次跑在搬移**之前**。
教训：**搬移函数之后必须重跑一次 typecheck/build**，再导出的名字不会自动进入本地作用域。
（`verify:dist` 当时显示 11/0 通过，是因为它读的是**上一次**的产物 —— 这一点同样要注意。）

## 五、**未覆盖**（不许写成已验证）

> ⚠️ **待人工判定项（不许用自动化代替）**：**界面的视觉与交互**。
> 本环境**跑不了浏览器**（`I8`），`verify:render` 用的是 `react-dom/server` 渲染字符串 ——
> 它只能证明"渲染得出来、文案在、属性对"，**证明不了**布局是否好看、动效是否顺、
> 暗色对比度是否够、抽屉在真机上是否跟手。**演示前必须人工走查一遍**。

走查清单与判据见 `specs/微积分学伴_界面验收清单.md` §12（V1.5）：

1. 宽屏左栏常驻、点功能项主区随之切换；
2. 窄屏（≤900px）左栏变抽屉，选中后自动收起；
3. 暗色模式下主色变亮档、无"深底深字"；
4. 对话流：新消息在**下方**、输入框**贴底**、`mock` 标记与验证状态仍在；
5. 动效为 180ms 淡入上移、**无弹跳**；系统"减少动态效果"开启后动效消失。

另如实登记：**语音输入的真实浏览器可用性**仍未实测（沿用 09-22 的口径，与本轮无关）。

# 2026-09-23 · UI 收敛（配色 / 文案 / 动效）＋ 测试材料库

> **本文来源**：全部为**本轮实测**。触发是用户三条要求：
> ① 去掉所有不必要的说明性灰色小字，**页面最多三种颜色：白绿黄**（省不下来的颜色先当"有冗余"查）；
> ② 生成**全方面**测试材料、统一放一个目录供调用；③ **所有交互必须带动画**，先做的越多越好。

## 一、配色：收敛到三个色族

**问题**：原 token 里有 5 个色族（白/绿/黄 + **红**(错误) + **蓝**(信息)）。

**做法**（只改 `:root`，**使用处一处未动** —— 变量名保留，值并入三族）：

| 原色族 | 并入 | 理由 |
|---|---|---|
| 红（`--err` / `--err-bg`） | **黄**（加深一档） | 靠**文案与图标**区分"警告 vs 失败"，不再靠颜色；错误仍一眼可辨（底色更深） |
| 蓝（`--info-bg` / `--info-text`） | **绿**（主色） | "正在处理中"本来就不是警告，用主色更合适 |

结果：**白（bg/card/text/border）＋ 绿（唯一主色）＋ 黄（唯一强调色）**。
暗色模式同口径（错误 = 亮黄档）。

**这条判据写进了 CSS 注释**，供后人遵守：
> 想再加一个颜色之前，先问一遍 —— **这里是不是有冗余内容可以先删？**

## 二、文案：删的是"解释性"，**留的是"真实性"**

按用户口径逐个视图筛，删掉 **5 处**（都是"解释系统会做什么"，按一下就知道）：

| 位置 | 删掉/精简的内容 |
|---|---|
| 材料面板 | 「上传讲义后，系统会抽出知识点、判断哪些前置知识你的材料没讲……」→ **整句删** |
| 材料面板 | 输入框 placeholder 的 4 行示例 → **压成 1 行**（"把讲义、题目或看不懂的段落粘贴到这里"） |
| 画像面板（空态） | 「轻路径提问不产生材料画像。上传讲义并解析后，这里会记录……」→ **缩成一句**「轻路径不产生材料画像」 |
| 画像面板（无条目） | 去掉"（原因见练习面板的说明）"这类指路，只留事实 |
| 图谱面板（空态） | 「图谱为空。解析材料后，概念层节点会出现在这里，可点击节点查看它的来源与验证状态。」→ **缩成**「图谱为空 · 解析材料后出现」 |
| 左栏 | 「轻路径 · 未创建材料会话」常驻小字 → **改到 `title`**（悬停可见），左栏更干净 |

**⛔ 明确不删的（这些不是"小字"，是诚实性红线）**：

- 「识别在你的浏览器里完成……服务端不做语音转写」（**且已有断言锁着**）；
- 「演示通道提示：当前解析结果由固定的演示数据生成」；
- 「画像只反映本会话，不会跨会话累计」「目前只有「补上这一段」会写入掌握状态与缺口历史」；
- 图谱面板三处（悬空关系说明、未判定说明、选中项不在图谱里的说明）；
- 「仅本标签页保存，关闭标签页即清空」。

> 删文案前**逐条查过断言**（`verify-render.tsx` / `verify-voice.ts`）与真实性义务 —— 这也是为什么改完
> `verify:render` 仍 **193 项 0 失败**：**一条断言都没被放宽**。

## 三、动效：9 类，全部只动 `transform` / `opacity` / 颜色

| # | 交互 | 动效 |
|---|---|---|
| 1 | 切换视图 | 主区内容**淡入上移**（260ms） |
| 2 | 任何按钮按下 | `scale(0.97)`（120ms）—— 手感反馈 |
| 3 | 卡片 / 主按钮悬停 | 上浮 2px ＋ 阴影 |
| 4 | 左栏项悬停 | 右移 2px |
| 5 | 输入框聚焦 | 主色描边 ＋ 3px 光晕 |
| 6 | 通知 / 提示条 | 自上滑入 |
| 7 | 对话消息、知识点卡片、材料列表 | **逐项 stagger 入场**（35ms 步进，第 6 项起封顶） |
| 8 | 「本页说明」折叠展开 | 内容淡入 ＋ 箭头旋转 |
| 9 | 标签 / 徽标 / 引用角标 | 背景过渡；角标悬停放大 1.12 |

**三条纪律**：只动非布局属性（否则长列表掉帧）；**不用弹跳**（要"经典"不要"活泼"）；
`prefers-reduced-motion` 用**通配符**降级（`*` ＋ `!important`），保证"一个都不漏"。

## 四、测试材料库：`fixtures/materials/`

**10 份**材料 ＋ `index.json`（清单：id / 文件 / 场景 / **预期**）＋ `load.mjs`（加载器）＋ `README.md`：

| id | 覆盖的场景 |
|---|---|
| `basic` | 最常规讲义（导数定义 / 几何意义 / 单调性判据） |
| `prerequisite-gap` | **只有结论、缺前置** → 测 MISSING 与一键补充 |
| `formula-heavy` | 公式密集（切线、极值）→ 测 LaTeX 与符号验证 |
| `out-of-scope` | 线性代数 → 测"**不得**硬抽微积分知识点充数" |
| `too-long` | **加载时重复 6 次 → 3778 字** → 测单次上限（不必把几千字写进仓库） |
| `tiny` | 一句话 → 边界 |
| `mixed-language` | 中英混排（derivative / 导数 不应被当两个知识点） |
| `ambiguous` | 表述含糊 → 应倾向 PENDING，不硬判已覆盖 |
| `with-exercises` | 含练习题 → 测练习路径与画像事件 |
| `plain-narrative` | 纯叙述无公式 → 公式应为**空数组**（≠「通道未接入」） |

**它有真实消费方**：`verify:flow` 新增 7 条断言（清单可读、字段齐、id 不重复、
超长材料**真的**超上限、用材料跑通 `/api/knowledge` 且产出知识点）⇒ `flow` 56 → **63**。

## 一、视觉接入（图片 → 文本）

### 1.1 落地内容

| 文件 | 作用 |
|---|---|
| `apps/server/src/parse/vision.ts` | 图片载荷校验（**按内容嗅探格式**，不看客户端声明）＋体积闸门＋交已接入的模型通道识别 |
| `apps/server/src/parse/vision-output.ts` | 模型输出的**结构化解析**：正文、公式（含字符偏移与 LaTeX）、图像描述、低置信度片段 |
| `apps/server/src/parse/capabilities.ts` | 识别通道能力声明：图片 = **服务端**识别（`available: true`）；语音 = 浏览器内置（`available: false`） |
| `apps/web/src/shared/lib/image-input.ts` | 前端图片读取与**就地纠错**输入 |
| `apps/server/scripts/verify-parse-vision.mjs` | **31 项**断言（含"该通的通、该拦的拦"） |

### 1.2 行为边界（诚实性口径）

- 图片**由服务端**识别为文本后，与文字材料走**同一条下游管道**，不因来源不同而走捷径；
- **语音不做**（负责人定"先视觉"）：`/api/parse` 语音路径**保持"未接入"**，由 `unavailable[]` 如实列出；
- **不编造数据**：定位不到正文的公式与低置信度片段**被丢弃**，不塞假偏移；`notToScale` 的示意图**不估算数值**；
- **失败不升级**：模型返回不可解析时降级为纯文本 + 一条低置信度说明，不把请求打成 500。

## 四、`content-disposition` 定案

**结论：该响应头是平台网关行为，不是本应用的代码问题。**

| 证据 | 内容 |
|---|---|
| 应用源码 | 全量检索 `apps/`、`packages/`、`scripts/`，**没有** `content-disposition` |
| 直连（显式禁用代理） | `/` 与 `/api/health` **都带**该头 → **排除**本机代理注入的可能 |
| 响应头 | `server: cbrgw`、`x-cloudbase-request-id` → 来自云托管网关，且**对 HTML 与 JSON 一视同仁** |

**仍未判定的一项（须知）**：浏览器点开链接究竟是"打开页面"还是"下载文件"。
`curl` 不能替代浏览器行为，**需人工点一次**；口径与判据见
`docs/specs/微积分学伴_界面验收清单.md` §9。

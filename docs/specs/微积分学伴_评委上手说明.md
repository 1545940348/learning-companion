# 用导数判断单调性（课堂笔记）

## 一、结论（直接可用的那部分）

判断函数在哪些区间上递增、在哪些区间上递减，有一个很快的办法 —— 看导数的符号：

- 在某个区间上，若 **f′(x) > 0**，则函数在这个区间上**递增**；
- 在某个区间上，若 **f′(x) < 0**，则函数在这个区间上**递减**；
- 若 **f′(x) = 0**，则函数在这一点的切线是水平的，这一带通常就是增减互换的地方。

## 二、用法：三步走

1. 求导函数 f′(x)；
2. 解不等式 f′(x) > 0 与 f′(x) < 0，把定义域切成若干区间；
3. 按切出来的区间写单调区间 —— 递增的写在增区间里，递减的写在减区间里。

做题时把 f′(x) 的符号变化列成表，单调区间一眼就能读出来。

## 三、例题

**例 1** 求 f(x) = x² 的单调区间。

f′(x) = 2x。f′(x) > 0 得 x > 0，f′(x) < 0 得 x < 0。
所以 f 在 (−∞, 0) 上递减，在 (0, +∞) 上递增。

**例 2** 求 f(x) = x³ − 3x 的单调区间。

f′(x) = 3x² − 3 = 3(x − 1)(x + 1)。

- x < −1 时 f′(x) > 0，递增；
- −1 < x < 1 时 f′(x) < 0，递减；
- x > 1 时 f′(x) > 0，递增。

所以减区间是 (−1, 1)，增区间是 (−∞, −1) 与 (1, +∞)。

**例 3** 求 f(x) = x³ 的单调区间。

f′(x) = 3x² ≥ 0 恒成立，只有 x = 0 处等于 0。
所以 f 在 (−∞, +∞) 上递增（x = 0 这一点不改变单调性）。

## 四、两个注意

1. **单调区间必须写在定义域内。** 比如 f(x) = 1/x 在 (−∞, 0) 与 (0, +∞) 上分别递减，
   但**不能**把两个区间并起来写成"在 (−∞, 0) ∪ (0, +∞) 上递减"——
   并起来之后，取 x = −1 与 x = 1 一比就会发现函数值反而变大了。
2. **f′(x) = 0 只是"这个人可能是转折点"，不是"一定是"。** 例 3 里 x = 0 处导数也是 0，
   但函数一直递增，那里并不是转折点。所以导数等于零的点要单独回代检查。

## 五、这节课留下的问题

笔记里只记了**结论和用法**：从头到尾都在用"导数"这个词，但**没有写导数是什么**，
也没有写"为什么 f′(x) > 0 就能推出函数递增"。

也就是说，这份笔记默认读者已经知道导数了。不知道的话，得先补上"导数"这一节，
再回来看这里的符号判定 —— 否则上面这几条结论只能死记，题目稍微换个样子就不会用。

## 六、我们刻意保留的边界（如实说，不藏着）

1. **冷启动**：服务平时缩容到 0，第一次访问可能要等十几秒到 30 秒，甚至先给一次错误页 —— 重试即可。
2. **真实模型下有些步骤真的要等**：上传讲义 → 抽知识点，**实测约 1 分钟**；补缺口约 **15 秒**。我们不假装它快。
3. **语音输入依赖浏览器**（Chrome / Edge 可用，Firefox 桌面版不支持）**且需要联网**；
   识别在**你的浏览器里**完成，**服务端不转写语音**。
4. **服务端的语音能力如实标为"未接入"** —— 界面上写得很清楚：
   这句指的是"服务端没有这项能力"，**不是**"语音输入不能用"。
5. **符号验证只覆盖四类断言**，超出课程范围或超出输入规模的，一律标「未验证」。
6. **「本页说明」里的"本页尚未接入"只剩一项**：服务端的历史会话列表（接口已经有了，页面还没用上）。
   —— 注意这是"**接口有了、页面没用上**"，不是"这项能力没做"。

## 0 这份清单的边界（先看）

| 项 | 说明 |
|---|---|
| **它能做什么** | 逐项给出「从哪进、怎么点、该看到什么」，让验收可执行、可判定、可复现 |
| **它不能做什么** | **不能替代浏览器视觉验证。** 开发环境无法安装 `agent-browser`（已知限制 `I8`），布局、配色、动画、真实点击链路**只能人工实点** |
| 自动覆盖到哪 | `npm run verify:render -w @lc/web`（**58 项**）以服务端渲染断言"渲染不抛异常"与"关键标注确实出现在 HTML 里"；交互态由 `verify:flow`（**32 项**，真实 HTTP）覆盖 |
| 判定符号 | ✅ 期望出现 ｜ ⛔ 期望**不**出现 ｜ 👁 只能人工判定 |

### 走查前置

```bash
# 服务端（mock 通道，无需密钥）
cd apps/server && MODEL_PROVIDER=mock PORT=3000 npx tsx src/index.ts
# 前端
npm run dev -w @lc/web        # http://localhost:5173
```

⛔ **必须在 mock 通道下走一遍、在真实通道下再走一遍**：两条路径的标注规则不同（见 §4）。

## 1 三入口齐全（说明书的硬要求）

| 编号 | 入口 | 操作 | 期望结果 |
|---|---|---|---|
| A-1 | 文字 | 「材料」面板查看输入区 | ✅ 有单次字数上限提示（3000 字）✅ 有提交按钮 |

## 2 六大面板与核心闭环（对应 §8.2 九步）

按 §8.2 的顺序走一遍，每步都能看到预期结果即算通过。

| 编号 | 闭环步骤 | 入口 | 操作 | 期望结果 |
|---|---|---|---|---|
| B-1 | 零材料提问 | 「答疑」面板 | 不传材料直接提问 | ✅ 回答标注**未基于你的材料**；✅ 提示可上传讲义获得更贴合的回答 |
| B-2 | 上传讲义 | 「材料」面板 | 粘贴一段含「单调性」的讲义并提交 | ✅ 材料卡片出现；✅ 页脚材料版本 `v1`；✅ 提示解析出 N 个知识点 |
| B-3 | 图谱构建 | 「图谱」面板 | 观察节点 | ✅ 节点数 ≥ 1；✅ 节点带状态文案；⚠️ **无边时明确说明"没有关系边"且界面不布线** |
| B-4 | 缺口发现 | 「知识点与前置依赖」 | 查看前置依赖区 | ✅ 单调性材料下，**导数**显示为 **`MISSING`／材料未覆盖**；✅ 给出理由 |
| B-5 | 一键补充 | 缺口行 | 点「补上这一段」 | ✅ 出现 **`AI 补充：非上传讲义内容`** 横幅；✅ 状态转为 `SUPPLEMENTED`／AI 已补充；✅ 验证状态显示**未验证** |
| B-6 | 符号验证 | 同上 + 页头徽标 | 观察验证状态 | ⛔ **当前不可演示**：`/api/health` 的 `verification.available` 为 `false`，页头显「符号验证：未接入」，`/api/gap` 停在 `SUPPLEMENTED`。**这是如实标注，不是缺陷**（`B3`） |
| B-7 | 继续答疑 | 「答疑」面板 | 基于新材料再问一次 | ✅ 回答标注**基于你的材料**；✅ 每块带来源类别与验证状态 |
| B-8 | 练习 | 「练习」面板 | 选主题与来源后取题 | ✅ 固定题与自编题可分；✅ 提交前**不显示答案**；✅ 自编题解析**不算作你材料的证据** |
| B-9 | 画像更新 | 「画像」面板 | 补充缺口后再看画像 | ✅ 掌握状态出现变化；✅ 说明「我已掌握」**不会把材料未覆盖改判为已覆盖**；✅ 说明 AI 已补充**不等于已验证** |

> `B-4`→`B-5` 是演示的主线。**缺口必须是"材料确实没讲"**，不是模型随手判的（用例 E1/E2）。

## 4 真实性与标注（§8.4 底线，逐条核对）

| 编号 | 场景 | 操作 | 期望结果 |
|---|---|---|---|
| D-1 | mock 通道 | `MODEL_PROVIDER=mock` 打开页面 | ✅ 页头**醒目横幅**，含「不代表真实模型输出质量」 |
| D-2 | mock 逐条标记 | 在 mock 下提问 | ✅ **每一条**回答都带 `mock 演示数据` 标记（不是只在页头提一次） |
| D-3 | 真实通道 | `MODEL_PROVIDER=deepseek` 且配好密钥 | ⛔ 不出现任何 mock 横幅与 `mock 演示数据` 标记（`verify:render` 有断言锁住） |

| D-5 | 未接入能力总览 | 页面页脚 | ✅ 列出尚未接入项：图片与语音识别、符号验证引擎、教师视图、多智能体编排、错题归因 |

## 5 错误态与重试（`§5.4`）

| 编号 | 场景 | 操作 | 期望结果 |
|---|---|---|---|
| E-1 | 服务端未启动 | 关掉服务端后打开页面 | ✅ 页头显「服务端未连接」，⛔ 不白屏 |
| E-2 | 可重试失败 | 制造一次超时（`MODEL_TIMEOUT` 或 `SESSION_STALE`） | ✅ 出现**真正的重试按钮**，点它重放同一动作 |
| E-3 | 不可重试失败 | 制造一次 400 入参错误 | ⛔ **不给**重试按钮（重试没有意义，给了只会误导） |
| E-4 | 失败保留输入 | 提交材料失败 | ✅ 输入框内容**仍在**；✅ 成功后才清空 |
| E-5 | 单飞 | 一次解析未完成时点答疑 | ✅ 拒绝并说明"上一个操作还没完成"；✅ 两个动作不会互相覆盖忙碌态 |
| E-6 | 版本过期 | 材料更新后再看旧回答 | ✅ 旧回答被标为**依据已更新**，或响应被丢弃并告知（用例 `E8`） |

## 6 窄屏与可用性（`P-A12`）

| 编号 | 场景 | 操作 | 期望结果 |
|---|---|---|---|
| F-1 | 双栏折叠 | 窗口宽度拖到 < 900px | 👁 布局变单列，两列内容不重叠 |
| F-2 | 手机竖屏 | 视口 ≤ 560px | 👁 单列 + 留白收紧；知识点卡片单列排布 |
| F-3 | 长公式 | 提交含超长 LaTeX 的材料 | 👁 **不撑破卡片、不出现横向滚动条** |
| F-4 | 长引用编号 | 展开依据详情中的长 `refId` | 👁 能断行，不溢出 |
| F-5 | 图谱 | 节点很多时 | 👁 图谱区**自身**横向滚动，整页不被撑宽 |
| F-6 | 缩放 | 浏览器缩放 150% | 👁 无内容被裁切 |

> `F-*` 全部只能人工判定（`I8`）。代码层已对 `overflow-wrap: anywhere`、`max-width: 100%`
> 与 `@media (max-width: 560px)` 做了防御，但**"写了 CSS"不等于"看起来对"**。

### 2.3 ⚠️ 修正：第 ② 条的根因判断（会决定"改哪里"）

报告把根因归为"`I13` 的判据写成 `materials.length > 0`" ——
即暗示应当**放宽判据**。核实后**根因不是这个**：

```bash
# 复现脚本：.learnbuddy/repro-2026-09-18/zero-material-supplement.mjs
① POST /api/session                     → 201，0 份材料
② POST /api/gap {materialVersion: 0}    → 200，补充块落盘，materialVersion=1
③ POST /api/tutor                       → 403 UNAUTHORIZED_CONTENT / retryable=false
④ POST /api/quiz {source:'material'}    → 400「还没有材料」
```

③ 之所以 403，直接原因是**模型侧返回了一个没有任何引用的 `ai-supplement` 块**，
而守卫要求"补充块必须引用到一个已授权来源"才能作为答案展示。继续往下查：

```js
// apps/server/src/model/index.ts
function mockTutor(materialIds, zeroMaterial) {   // ← 只收 materialIds
  const sourceType = materialIds.length > 0 ? 'material' : 'ai-supplement';
  const citations  = materialIds[0] ? [...] : [];  // ← supplementIds 从未被使用
```

`parseRefIds()` **已经**能把 `【系统补充 <id>】` 解析出来，但 `mockTutor` 只接收
`materialIds` → 只要"有补充块、没有学生材料"，mock **恒**返回无引用的补充块。
**所以这是 mock 的保真度缺口（本轮新登记 `I31`），不是判据本身错。**
真机模型拿到的提示词里带补充块 refId，通常会引用它。

因此 ② 拆成两个问题，分开决策：**(a)** 守卫对"无引用但来自已授权补充块"的回答该拒还是
该收下并标 `basedOnMaterial=false`？**(b)** mock 要不要能引用补充块？
**两项都需要拍板**（`I29`），本轮不动 —— 照报告原话放宽判据，会把一个**真实性守卫**
改成"无引用也可展示"，方向相反。

## 6 本轮顺带记录的两条环境事实

1. **`npm run build` 在本机会直接失败**：`tsup ... --clean` 要删除
   `apps/server/dist/index.js`，被 `safe-delete` 垫片拦下（
   `Error: [safe-delete] 操作失败: … trash operation: Unknown`）。
   必须先 `npm run build:clean`（它是**改名挪走**，不是删除）再 `build`。已写进技能。
2. **不要给 Node 脚本传 MSYS 风格路径**：`PACK_DEPLOY_OUT="$PWD/..."`
   （`/d/smallbox/...`）会被 `path.resolve` 当成"当前盘符的根相对路径"，
   产出 `D:\d\smallbox\...`。用 `D:/...` 形式。

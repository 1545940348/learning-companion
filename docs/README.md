# docs 目录导览

> 整理时间：2026-09-17 ｜ 整理依据：V2.0 对齐后确认「全量设计先收入 plan」并同步收口文档结构

## 目录结构

```
docs/
├── 微积分学伴_项目说明书.md            工作正本（当前 V2.0）
├── 大湾区AI_Coding创新大赛_赛事手册.md  赛事约束正本
├── 赛题意图与产品设计分析.md            赛题意图解码与说明书审查
├── README.md                          本文件
├── plans/          每轮开始前：目标、任务分解、验收条件、允许修改目录
├── changelogs/     每轮结束后：改了什么、为什么、影响模块、验收结论
├── reviews/        每轮结束后：AI 输出核对，必须含被否决或被修改的记录
├── tech/           重大决策：选型、契约变更、取舍理由、已知限制
├── designs/        设计稿与方案母本（说明书的上游输入）
└── archive/        原始交付件（.docx 等不可编辑留档）
```

## 命名规范

- 四类留痕文档：`YYYY-MM-DD-<主题>.md`，日期为**实际撰写日**
- 成员归属可选前缀 `-A-` / `-B-` / `-C-`，用于同一轮内区分三人产出
- `designs/` 与 `archive/` 同样按 `YYYY-MM-DD-<主题>.<ext>` 命名
- 三份工作正本（说明书、赛事手册、赛题意图分析）**保留原名不放子目录** —— 历史
  changelog / plan / review 中已按 `docs/微积分学伴_项目说明书.md` 全路径引用，
  移动会破坏可溯源链。历史文档不得事后改写（§8.2）。

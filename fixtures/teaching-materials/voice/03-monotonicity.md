来，讲一个判断单调性的快办法，考试很好用。

你不用一个一个比较函数值大小，只看导数的符号就行。
在哪个区间上导数大于零，函数就在那儿递增；导数小于零的区间，函数就递减；
导数等于零的那些点，通常是增减互换的地方。

具体做三步。第一步，把导函数求出来。第二步，解导数大于零和小于零这两个不等式，
把定义域切成好几段。第三步，照着段写单调区间 —— 哪一段在增，哪一段在减。

举个例子，f(x) 等于 x 平方。导数等于 2x。大于零是 x 大于 0，小于零是 x 小于 0。
所以它在负无穷到 0 上递减，在 0 到正无穷上递增。

再来一个，f(x) 等于 x 立方减 3x。导数等于 3x 平方减 3，提个 3 出来就是 3 倍的 (x 减 1)(x 加 1)。
x 小于负 1 的时候导数大于零，递增；负 1 到 1 之间导数小于零，递减；x 大于 1 又递增。
所以减区间是 (负 1, 1)，增区间是负无穷到负 1 和 1 到正无穷。

最后两个坑。第一，单调区间必须写在定义域里面，别把断开的两个区间用并集符号连起来写。
第二，导数等于零的地方不一定是转折点，比如 x 立方在 0 处导数也是零，但它一直在递增 ——
所以导数等于零的点要回代检查一下。

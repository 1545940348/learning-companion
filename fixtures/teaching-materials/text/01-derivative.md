# 导数：从平均变化率到瞬时变化率（讲义）

## 一、平均变化率

设函数 y = f(x) 在点 x₀ 附近有定义。当自变量从 x₀ 变到 x₀ + Δx 时，函数值从 f(x₀) 变到 f(x₀ + Δx)，
两者的比值

    Δy / Δx = [ f(x₀ + Δx) − f(x₀) ] / Δx

叫做函数在区间 [x₀, x₀ + Δx] 上的**平均变化率**。

它的几何意义很直白：在图像上取 P(x₀, f(x₀)) 与 Q(x₀ + Δx, f(x₀ + Δx)) 两点，
平均变化率就是**过这两点的割线 PQ 的斜率**。所以平均变化率描述的是"这一段整体平均涨得多快"。

## 二、瞬时变化率：让 Δx 趋于零

平均变化率看不出"某一点"的涨落 —— Δx 取得大一点小一点，答案就变了。
要描述**某一瞬间**的快慢，就得让 Δx 无限接近 0。如果

    lim (Δx → 0) [ f(x₀ + Δx) − f(x₀) ] / Δx

存在，就把这个极限叫做函数 f 在点 x₀ 处的**导数**，记作 f′(x₀)，
也可以写成 y′|₍x = x₀₎。

这就是导数的定义：**导数是平均变化率当 Δx → 0 时的极限**。

## 三、导数的几何意义

Q 沿曲线向 P 靠拢时，割线 PQ 绕着 P 转动。当 Q 无限接近 P 时，割线的极限位置就是
**曲线在 P 点处的切线**。于是：

> **f′(x₀) 就是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。**

所以切线不是"只碰到曲线一次的直线"这种含糊的说法，而是**割线的极限位置**。

## 四、例题

例：求函数 f(x) = x² 在 x₀ = 1 处的导数。

按定义算：

    f′(1) = lim (Δx → 0) [ (1 + Δx)² − 1² ] / Δx
          = lim (Δx → 0) [ 2Δx + (Δx)² ] / Δx
          = lim (Δx → 0) (2 + Δx)
          = 2

所以 f′(1) = 2。也就是说，抛物线 y = x² 在点 (1, 1) 处的切线斜率是 2，
这条切线的方程是 y − 1 = 2(x − 1)，即 y = 2x − 1。

## 五、这节课要记住的三件事

1. 平均变化率 = 割线斜率；瞬时变化率（导数）= 切线斜率。
2. 导数的定义是一个极限，不是"套公式"。
3. 有了导数，才谈得上用它去判断单调性、求极值 —— 后面几节都建立在这一节之上。

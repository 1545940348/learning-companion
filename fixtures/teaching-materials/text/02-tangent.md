# 切线方程怎么求（课堂笔记 · 公式版）

## 一、核心公式

曲线 y = f(x) 在点 (x₀, f(x₀)) 处的切线方程是：

    y − f(x₀) = f′(x₀) · (x − x₀)

拆开看，只有两样东西要算：

1. **切点的纵坐标** f(x₀) —— 把 x₀ 代进原函数；
2. **切线的斜率** f′(x₀) —— 把 x₀ 代进导函数。

两点信息（一个点 + 一个斜率）就唯一确定一条直线，所以这个公式没有多余的自由度。

## 二、例题 1：抛物线

求 y = x² 在 x = 1 处的切线方程。

- f(1) = 1² = 1，切点 (1, 1)；
- f′(x) = 2x，所以 f′(1) = 2；
- 代入公式：y − 1 = 2(x − 1)，即 y = 2x − 1。

## 三、例题 2：三次函数

求 y = x³ − 3x 在 x = 0 处的切线方程。

- f(0) = 0³ − 3·0 = 0，切点 (0, 0)；
- f′(x) = 3x² − 3，所以 f′(0) = −3；
- 代入公式：y − 0 = −3(x − 0)，即 y = −3x。

## 四、例题 3：切线与单调性的交界

求 y = x³ − 3x 在 x = 1 处的切线方程。

- f(1) = 1 − 3 = −2，切点 (1, −2)；
- f′(1) = 3 − 3 = 0；
- 代入公式：y − (−2) = 0 · (x − 1)，即 y = −2。

斜率为 0 的切线是一条**水平线**。这条水平切线出现在 x = 1 处不是巧合：
在这个点左右，函数先减后增，所以这里正好是一个极小值点，
而极值点处的导数一定是 0。

## 五、两个容易错的点

1. **切点不一定在曲线上"碰一下就走"。** 切线与曲线还可以有别的交点。
   比如 y = x³ 在 (0, 0) 处的切线是 y = 0，而这条线与曲线在原点相交后直接穿过去。
   判断切线靠的是"割线的极限位置"，不是"交点个数"。
2. **别把 f′(x₀) 当成切点的纵坐标。** f′(x₀) 是**斜率**，f(x₀) 才是纵坐标。
   两个数写反了，直线还是条直线，但位置全错。

## 六、导数公式表（本节用到的那几个）

| 函数 | 导函数 |
|---|---|
| y = C（常数） | y′ = 0 |
| y = x | y′ = 1 |
| y = x² | y′ = 2x |
| y = x³ | y′ = 3x² |
| y = x³ − 3x | y′ = 3x² − 3 |

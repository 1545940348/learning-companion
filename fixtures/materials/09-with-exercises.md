# 单调性与极值（含练习）

## 要点

对可导函数 f，在区间 I 上：

- f′(x) > 0 ⇒ f 在 I 上递增；
- f′(x) < 0 ⇒ f 在 I 上递减；
- f′(x) = 0 的点是驻点，需再看两侧符号才能判断是否为极值点。

## 例题

**例 1** 求 f(x) = x² − 4x + 3 的单调区间与极值。

解：f′(x) = 2x − 4，令 f′(x) = 0 得 x = 2。x < 2 时 f′ < 0，递减；x > 2 时 f′ > 0，递增。
故极小值为 f(2) = −1。

**例 2** 讨论 f(x) = x³ − 3x² 的单调性。

解：f′(x) = 3x² − 6x = 3x(x − 2)，驻点为 x = 0 与 x = 2。
在 (−∞, 0) 与 (2, +∞) 上递增，在 (0, 2) 上递减；极大值 f(0) = 0，极小值 f(2) = −4。

# 切线方程与极值

## 一、求切线方程的三步

以 f(x) = x² 在 x = 1 处为例。

1. 求导数值：f′(x) = 2x，所以 f′(1) = 2，这是切线斜率；
2. 求切点纵坐标：f(1) = 1；
3. 用点斜式写直线：y − 1 = 2(x − 1)，整理得 y = 2x − 1。

## 二、求极值的步骤

1. 求 f′(x)，令 f′(x) = 0 解出**驻点**；
2. 看 f′ 在驻点两侧的符号是否变化：由正变负是极大值点，由负变正是极小值点；
3. 把驻点代回 f(x) 得到极值。

例：f(x) = x³ − 3x。

f′(x) = 3x² − 3 = 3(x − 1)(x + 1)，驻点为 x = −1 与 x = 1。

- 在 x = −1 处 f′ 由正变负 ⇒ 极大值 f(−1) = 2；
- 在 x = 1 处 f′ 由负变正 ⇒ 极小值 f(1) = −2。

单调区间：在 (−∞, −1) 与 (1, +∞) 上递增，在 (−1, 1) 上递减。

## 三、三条常用结论

- f′(x) > 0 ⇒ 该区间上递增；f′(x) < 0 ⇒ 该区间上递减；
- 可导函数的极值点**一定**是驻点；
- 驻点**不一定**是极值点（例如 f(x) = x³ 在 x = 0 处）。

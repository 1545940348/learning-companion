## 导数与变化率（讲义片段）

设函数 f 在区间 I 上有定义。对 I 内任意两点 x₁、x₂，比值 [f(x₂) − f(x₁)] / (x₂ − x₁)
刻画的是函数在这两点之间的**平均变化率**。把其中一点固定为 x、另一点写成 x + Δx，
就得到平均变化率的常用形式：

    [f(x + Δx) − f(x)] / Δx

让 Δx 趋于 0，若极限存在，则称该极限为 f 在 x 处的**瞬时变化率**，也就是导数 f′(x)。

从几何上看，平均变化率是割线的斜率；让 Δx 趋于 0，割线绕着定点旋转，极限位置就是切线。
所以 f′(x₀) 等于曲线在 (x₀, f(x₀)) 处切线的斜率。

导数的符号还能读出单调性：在某区间上 f′ > 0 说明曲线一路向上，函数在该区间递增；
f′ < 0 说明一路向下，函数递减。这给了判断单调性的一条捷径：不必逐点比较函数值，
只要考察导数的符号。

需要注意两点。第一，f′ 的符号条件必须在**整个区间**上成立，才能得出区间上的单调性；
单点的导数值为正只说明局部。第二，f′ = 0 只是"可能是极值点"的必要条件：
f(x) = x³ 在 x = 0 处导数为零，但函数在该点两侧都递增，因此不是极值点。

此外，可导必连续，但连续不一定可导。f(x) = |x| 在 x = 0 处连续，左右导数却不相等，
因此在该点不可导。这条差异在画图像时很关键：尖点处没有切线。

# 导数的定义与几何意义

## 1. 从平均变化率到瞬时变化率

设函数 f(x) 在点 x₀ 的某个邻域内有定义。当自变量从 x₀ 变到 x₀ + Δx 时，函数值的改变量为
Δy = f(x₀ + Δx) − f(x₀)，两者之比

    Δy / Δx = [f(x₀ + Δx) − f(x₀)] / Δx

称为函数在区间上的**平均变化率**，它刻画的是这段区间上"平均的变化快慢"。

当 Δx → 0 时，如果这个比值的极限存在，就称这个极限为 f(x) 在 x₀ 处的**导数**，记作 f′(x₀)：

    f′(x₀) = lim(Δx→0) [f(x₀ + Δx) − f(x₀)] / Δx

## 2. 几何意义

导数的几何意义是曲线 y = f(x) 在点 (x₀, f(x₀)) 处**切线的斜率**。割线斜率的极限就是切线斜率 ——
这也是"切线"的定义方式：它不是"与曲线只有一个交点的直线"（那对抛物线成立，对三次曲线不成立），
而是在该点处与曲线相切的那条直线。

## 3. 导数的符号与单调性

在区间 I 上，如果对任意 x ∈ I 都有 f′(x) > 0，那么 f 在 I 上**严格递增**；
如果都有 f′(x) < 0，那么 f 在 I 上**严格递减**。

直观理解：f′(x) 是切线的斜率，斜率为正说明曲线"往上走"，斜率越大上升越快。

⚠️ 容易忽略的地方：f′(x₀) > 0 只说明在 x₀ 附近递增（局部）；
要说在整个区间上单调，必须要求该区间上**处处**满足符号条件。

## 4. 常见误解

- 误：f′(x₀) > 0 就说明函数在整个定义域上递增。反例：f(x) = x³ − 3x 在 x = 2 处导数为 9 > 0，
  但它在 x = 0 附近是递减的。
- 误：导数为 0 的点一定是极值点。反例：f(x) = x³ 在 x = 0 处 f′(0) = 0，但它不是极值点。
